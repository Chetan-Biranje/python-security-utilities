# Contributing

Contributions that improve accuracy, maintainability, documentation or defensive security are welcome.

1. Open an issue describing the proposed change, unless it concerns a vulnerability; use [SECURITY.md](SECURITY.md) for private reporting.
2. Fork the repository and create a focused branch.
3. Follow existing conventions, update relevant documentation and run any available tests.
4. Submit a pull request describing the change, validation performed and known limitations.

Use synthetic data and authorized test environments. Never commit credentials, personal information or confidential vulnerability reports. Keep changes compatible with the repository's existing license and respect third-party attribution.
